# Business model

The software is free under the Apache License, Version 2.0. See [LICENSE](../LICENSE) and [LICENSING-HISTORY.md](../LICENSING-HISTORY.md). Paid are services and commitments. For Ferrum that offer is Ferrum Professional. Prices are on the [consulting page](https://synapticfour.com/en/consulting/).

This page is not legal advice and not a price list.

## What stays free

The code in this repository, including the GA4GH interfaces, has no runtime licence key.

[Ferrum Lab Kit](https://github.com/SynapticFour/Ferrum-Lab-Kit) writes deployment files around Ferrum. It does not add a second copyright licence on the Ferrum binaries. Lab Kit's own licence is in that repository. PDF report output there still checks `FERRUM_LAB_KIT_LICENSE_KEY`, because that is what the Lab Kit code does.

## What is paid

Ferrum Professional is a service and a set of commitments. It is not a copyright licence on the code. The same is true of a guided pilot, support, and a written agreement. There is no combo SKU with Solum or BioResearch Assistant. Solum stays under the Business Source License 1.1 in its own repository.

Contact: [contact@synapticfour.com](mailto:contact@synapticfour.com). How to ask: [COMMERCIAL.md](COMMERCIAL.md).

For product boundaries between Ferrum and packaging tools, see [GA4GH-LAB-KIT-SCOPE.md](GA4GH-LAB-KIT-SCOPE.md) (German).
