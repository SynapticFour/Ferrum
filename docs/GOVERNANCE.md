# Continuity

Synaptic Four is a German sole proprietorship (Einzelunternehmen). One human
maintains these repositories today. There is **no** second committer with
merge rights, **no** code escrow, and **no** secondary-operator guarantee.

Deployments run on infrastructure you control. Source is public (BUSL-1.1 on
this repo). If a procurement needs succession clauses, raise that in the first
conversation — we will not invent a team or an escrow that does not exist.
