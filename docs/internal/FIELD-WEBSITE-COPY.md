## Feature bullets (EN)

- **Offline-first:** SQLite + local SSD; JWKS cache for days without internet
- **MinION-ready:** Streaming ingest, QC metrics, optional hub WES variant calling
- **Consent-aware sync:** DUO-filtered queue; sneakernet USB export
- **Open standards:** GA4GH DRS 1.4, Beacon v2, Crypt4GH, ferrum-meta metadata
- **Field provenance:** Residency audit chain; backup/restore CLI
